# RNA-seq Gene Expression Analysis

This is a mini bioinformatics portfolio project focused on RNA-seq gene expression data analysis, visualization, and clear scientific documentation.

The project demonstrates how gene expression data can be organized, explored, visualized, and summarized in a reproducible way.

---

## Goal

The goal of this project is to show practical skills in:

- RNA-seq expression data preparation
- sample metadata organization
- exploratory data analysis
- PCA visualization
- volcano plot visualization
- heatmap visualization
- short biological interpretation

---

## Workflow

1. Prepare expression matrix and sample metadata
2. Check dataset structure and quality
3. Normalize or prepare expression values
4. Explore sample relationships using PCA
5. Visualize differential expression using a volcano plot
6. Show expression patterns using a heatmap
7. Summarize the results in a short report
